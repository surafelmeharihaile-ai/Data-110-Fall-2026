Project 1 : Distribution of VA Disabilities.

For this project, I will explore a data-set that has information about VA disability compensation recipients across geographic areas in the United States. The data-set contains 3,148 rows and 14 columns, including state, county name, FIPS code, total recipients, disability-rating categories, age groups, and sex. My research question is Which VA disability-rating categories have the highest numbers of recipients, and how does the distribution compare across a few states? 

Data source : VA Disability

Here, I examined the data types to determine whether the recipient counts were stored as numbers or text. As the results show, several count columns are currently stored as text because the numbers contain commas. These may need to be converted before calculations. I also checked the data-set for missing values to identify columns with incomplete information. There doesn’t seem to any missing values here. Finally, I looked for empty strings in the data, because the some info not being available. Empty strings will affect the conversion of characters to numbers, so they have to be filtered out.

“Veterans_clean” is the cleaned version of the original data. Using “filter()”, it removes rows that contain empty strings in any of the columns. This makes sure all the retained records have values in all the specified columns before further analysis.

Converting the values to numeric:

#Compensation
VTDCR <- as.numeric(gsub(",", "",veterans_clean$Total..Disability.Compensation.Recipients))
#Ratings
num_rating_0_20<-

num_rating_30_40<-
  as.numeric(gsub(",", "", veterans_clean$SCD.rating..30..to.40.))

num_rating_50_60 <-
  as.numeric(gsub(",", "", veterans_clean$SCD.rating..50..to.60.))

num_rating_70_90 <-
  as.numeric(gsub(",", "", veterans_clean$SCD.rating..70..to.90.))

num_rating_100 <-
  as.numeric(gsub(",", "", veterans_clean$SCD.rating..100.))

As mentioned previously, the data-set originally stored the recipient counts as character variables. For example, a value such as “2,949” was stored as a text rather than a number. I used “gsub()” to remove the commas and “as.numeric()” to convert the values into numbers.

Calculating the total recipients for each rating category:

rating_totals <- data.frame(
  Rating = c("0%-20%", "30%-40%", "50%-60%", "70%-90%", "100%"),
  Recipients = c(
    sum(num_rating_0_20),
    sum(num_rating_30_40),
    sum(num_rating_50_60),
    sum(num_rating_70_90),
    sum(num_rating_100)
  )
)

This bar chart compares the total number of VA disabilities compensation recipients across five disability rating categories. The graph shows that the 70%-90% and 100% categories have the highest reported recipients. The 30% -40% category has the lowest amount of recipients. For the 0%-20% category as well as the 30% -40% one the count runs to a little above 500,000 recipients. An important information is that these ratings represent the VA’s assessment of the severity of service-connected disabilities. Higher ratings generally indicate greater disability.

Before the next visualization, this code calculates the percentage of VA disabilities compensation recipients who have 100% disability rating. It then stores the calculated percentage in a new column called Pct_100 in the veterans_clean data-set.

veterans_clean %>%
  filter(State %in% c("Maryland", "Virginia", "Pennsylvania")) %>%
  ggplot(aes(x = State, y = Pct_100, fill = State)) +
  geom_boxplot() +
  scale_fill_discrete() +
  labs(
    title = "County-Level Counts of 100% Disability Ratings",
    x = "State",
    y = "Percentage of Recipients with a 100% Rating",
    fill = "State",
    caption = "U.S. Department of Veterans Affairs"
  ) +
  theme_minimal()

The last visualization compares the percentage of VA disability compensation recipients with a 100% disability rating across counties in Maryland, Pennsylvania, and Virginia. Maryland has the highest median percentage, at 29%, followed by Virginia at about 28%. Pennsylvania has the lowest median, at around 24%. Virginia shows a wider spread of county percentages. Maryland also has few counties with unusually high percentages, while Pennsylvania’s county percentage appear more closely grouped.
